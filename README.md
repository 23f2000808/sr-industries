## ✨ Features & Architecture

### 1. Botanical Heritage Design System
- **Colors:** Deep Forest Green (`#003527`, `#064e3b`), Subtle Gold (`#735b24`, `#b4975a`), and Warm Cream background (`#f8faf6`).
- **Typography:** Display & Headlines in `Playfair Display` serif, Body & Data in `Inter` sans-serif.
- **Micro-Interactions:** Soft ambient shadows (`ambient-shadow`), 1px gold borders (`gold-border`), smooth hover elevation (`hover-lift`), and glassmorphism sticky navigation.

- **Direct WhatsApp Integration:** 1-click pre-filled inquiry links to `+91 7409940333`.

## 🚀 Getting Started

### Prerequisites
- Node.js >= 18.0.0
- npm >= 9.0.0

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/23f2000808/sr-industries.git
cd sr-industries

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build

```bash
# Run TypeScript compilation and build production bundle
npm run build

# Preview production build locally
npm run preview
```
